# e-invoicing-manager

A web application that allows users to upload XRechnung files (UBL/CII), parse them, check them against business rules and view and search invoices per company.

## Status

in progress

## Note

The app checks invoices against a selection of the official business rules and explains problems in plain language. It's not a legally binding validator. The officil check against the complete rule set is done by the KoSIT validator.
